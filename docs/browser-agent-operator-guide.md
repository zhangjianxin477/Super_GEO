# Browser Agent 操作与隐私说明

## 适用范围

Browser Agent 是本产品进行**真实网页 GEO 基线采集**的正式路径。它在客户本地或客户受控环境中运行，与已登录、可见的浏览器协作，获取平台页面实际可见的回答与引用链接。

这条路径与 Provider API、企业网关和 MCP 研究连接器不同：后者可用于 Query 研究、结构化分析或补充观察，但**不得**完成或替代真实网页 GEO 基线。

## 角色与权限

- **工作区管理员**：创建一次性配对码、查看设备状态、撤销设备；不得通过产品界面读取本地 Agent 令牌。
- **客户侧操作者**：在受控计算机上双击本地 Agent；在 GEO 系统内显式点击「启动本地自动采集」。首次登录、验证码或平台提示只在独立可见的受控浏览器窗口中由操作者处理，扩展弹窗仅作为排障兜底。
- **分析人员 / 审核人员**：查看任务、原始证据和采集方式；审核 Browser Agent 或人工兜底提交的证据。

一次性配对码有效期为 15 分钟，只在创建时显示一次。服务端仅保留其 SHA-256 哈希；配对完成后，本地 Agent 得到可撤销令牌，服务端同样仅保存令牌哈希。

## 操作流程

1. 管理员在「Harness 管理 → 添加设备」创建并复制一次性配对码。该码仅用于第一次配对，有效期为 15 分钟。
2. 客户侧操作者双击 `browser-agent/Start-GEO-Agent.cmd`。首次启动会弹出配对窗口：粘贴一次性配对码、确认企业 GEO 系统地址并为设备命名；无需打开终端或输入 Node 路径。启动器负责查找本机 Node、后台启动本地 Agent，并只监听 `127.0.0.1`。日常启动器只保持 Agent 在线，不会主动打开浏览器。
3. 在 GEO 系统的「Query 基线 → 任务执行与证据复核」创建豆包测试批次，确认该设备显示在线后，点击「启动本地自动采集」。这是每个批次必须有的显式授权，默认 5 分钟后失效。
4. 本地 Agent 会自动打开或聚焦独立受控 Edge Profile、加载本项目扩展并打开豆包；扩展收到同一授权后自动逐条执行当前批次。无需在浏览器扩展中点击“开始”。首次使用该独立 Profile 时，操作者只需在可见窗口正常登录豆包，并确认平台条款允许该使用方式。
5. 批次页实时显示「已发出授权 → 本地 Agent 已确认 → 正在打开浏览器 → 等待登录/正在自动采集 → 已完成」以及待执行、回传数量、最后心跳和失败原因。点击「取消本次自动采集」后，Agent 不会再领取后续 Query；已回传证据会保留。
6. Agent 仅领取已分配给该设备、该平台、该测试批次的任务；扩展按适配器规则采集页面**可见**回答与可见引用 URL。
7. 系统保存不可变证据包、采集时间、平台/适配器版本、是否新会话及可识别的搜索状态，并由审核人员复核。

### 登录或页面异常

- **登录失效**：批次页显示「等待浏览器登录或页面就绪」。在自动打开的独立窗口完成登录后，扩展会自动恢复当前授权；如已过期，回到批次页重新点击「启动本地自动采集」。
- **验证码、账户限制或页面结构变化**：自动化会停止，批次页显示原因；系统不会尝试绕过。可在同一任务里使用受控人工导入，或处理完问题后在系统中重新发起一次授权。
- **需要手动排障**：扩展弹窗中的「手动兜底启动」仍可用；它不是正常生产流程。也可运行 `Start-GEO-Agent.ps1 -OpenBrowser` 只打开受控浏览器窗口检查登录状态。

## 安全与平台边界

Browser Agent 和扩展绝不：

- 读取、上传、存储或返回密码、Cookie、完整浏览器 Profile、完整页面 HTML 或未关联本次任务的浏览记录；
- 自动登录、处理验证码、绕过 CAPTCHA / anti-bot、访问控制、速率限制或平台服务条款；
- 在操作者未显式启动批次时操作第三方平台网页；
- 将 API、网关或 MCP 输出标记为网页 GEO 基线。

检测到登录过期、验证码、账户限制、页面结构不可识别、用户暂停或回答不完整时，扩展必须停止，并把当前任务标记为「需要人工处理」。系统将该任务回落为同一任务身份下的 `controlled-manual` 人工录入；报告必须展示采集方式和限制，不能把人工兜底称为自动采集。

## 数据留存与审计

每个完成的 Browser Agent 任务保留：工作区、任务与 Query 标识、原始可见回答、页面可见引用 URL、观测时间、Agent/适配器版本、最小化采集元数据和证据哈希。系统记录配对、领取、完成、失败/转人工、人工提交和审核审计事件。

本地配置位于操作者系统用户目录，仅用于运行该 Agent。企业应按自己的数据保留、终端管理和第三方平台合规政策进行部署与撤销。管理员撤销设备后，其令牌立即不可再用于心跳、领取或提交结果。

## 适配器变更管理

每个运行保存创建时的 Browser Agent / 适配器快照。后续设备能力或适配器版本改变，不得改写已创建运行的快照。页面或平台规则变化时，适配器应保守暂停并转人工；恢复自动运行前需要完成测试、版本标识和管理员确认。
