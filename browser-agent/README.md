# GEO Local Agent（Windows 一键启动器）

> 当前版本提供 **七个国内 AI 平台的真实网页 GEO 基线采集**：豆包、元宝、DeepSeek、文心一言、智谱清言（GLM）和 Kimi。平台操作发生在客户本地的可见、已登录浏览器中；系统不会用 API/MCP 结果替代真实网页基线。

## 一次性配对

1. 在 GEO 系统的「Harness 管理」创建设备和一次性配对码，然后点击「复制配对码」。
2. 双击 `Start-GEO-Agent.cmd`。首次启动会依次弹出三个小窗口：粘贴配对码、确认 GEO 系统地址、为这台电脑命名。**不需要打开 PowerShell，也不需要手动加载扩展。**

- 配对码仅填写真实内容，**不要包含 `<` 与 `>`**；有效期为 15 分钟。
- 本机开发默认系统地址是 `http://127.0.0.1:8787`；共享给同事或生产部署时，请填写企业实际 GEO 系统地址。
- 配对成功后，令牌只保存在当前 Windows 用户的 `~/.geo-browser-agent/config.json`。
- Agent 版本 `0.3.15` 会在心跳中声明七个已安装适配器；旧版 Agent 会由启动器安全重启，以加载新版扩展。

## 每次使用

之后只需双击：

```text
Start-GEO-Agent.cmd
```

它会：

1. 检查并后台启动本地 Agent（只监听 `127.0.0.1:23891`）；
2. 保留一个独立受控 Edge Profile 及其本地登录态；
3. 等待 GEO 系统内一次明确、5 分钟有效的「启动本地自动采集」授权；
4. 按本次所选平台自动打开对应官网、加载扩展、逐条输入 Query、采集页面可见回答与引用资料，并回传系统。

> **选择哪个平台，就只执行那个平台的任务。** 本次授权不会派发给其他平台标签页，也不会复用上一轮回答或引用资料。

首次使用某个平台时，在自动打开的受控浏览器窗口中按平台正常完成登录。若出现登录失效、验证码、人机验证、账户限制或页面结构无法识别，Agent 会停止并标记「需要人工处理」；不会自动登录、绕过验证或猜测页面内容。

本地运行日志位于 `%LOCALAPPDATA%\GEO Browser Agent\logs\`。如果系统显示设备离线，可检查 `http://127.0.0.1:23891/v1/health`；若扩展显示旧版本，请关闭受控 Edge 窗口后重新双击启动器。

## 企业与多平台交付边界

每位同事使用自己的 Windows 用户、自己的 Browser Agent 配对和自己的已登录平台账户。服务端可以撤销单个设备；本地 Agent 不读取、上传或存储密码、Cookie、完整浏览器 Profile。

本地 Agent 与平台适配器按插件边界交付。每个适配器仅采集与当前任务相关的**页面可见**回答、可见 URL、可见资料标题/关键词及最小化元数据；不会收集完整页面 HTML 或无关浏览历史。新平台必须通过页面结构、登录/验证码降级、引用采集和平台合规测试后才会启用。
